# 大陆金融 IT 服务商全景 (2026)

本文档聚焦**面向银行及金融机构的 B2B 金融 IT 解决方案供应商**，覆盖核心系统、信贷、渠道支付、财富管理、基础中间件等领域，提供能力矩阵、软件系统功能点与典型接口参考设计。

> ⚠️ **定位说明**
> - 本文档覆盖的是**项目交付型 IT 解决方案商**（如宇信、长亮），其系统多为金融机构私有部署，接口规范以项目合同附件为准。
> - 第三方可对接 API 服务（如支付宝、微信支付、Stripe 等）请见 [industry-vendors.md](./industry-vendors.md)。
> - 本文档中的接口设计为**基于行业惯例的参考设计**，标注 `⚠️ 私有部署参考设计`，实际接入以合同为准。

## 2. 银行核心系统

### 2.1 长亮科技

- **定位**：银行核心系统龙头，客户覆盖全类型银行（国有大行、股份制、城商、农商、民营）。
- **代表产品**：Sunline CoreBanking、分布式核心系统。
- **功能点（模块级）**：
  - 存款模块：活期/定期/通知/保证金存款，~200 功能点
  - 贷款模块：自营/委托/银团贷款，~150 功能点
  - 内部账与总账：科目管理、分户账、日终轧账，~100 功能点
  - 资金清算：人行大额/小额、同城票据，~120 功能点
  - 客户信息管理 (CIF)：个人/对公客户、关联关系，~80 功能点
- **详细 API 参考**：[📄 长亮科技核心系统接口参考](./vendors/solutions/changliang.md)

### 2.2 神州信息

- **定位**：核心系统 + Sm@RT 系列产品，服务国有大行与股份制。
- **代表产品**：ModelBank⁵、Sm@RT 核心。
- **功能点**：
  - 核心账务：本外币一本账、计提摊销
  - 客户统一视图：360 度画像、KYC
  - 风险管理：信用/市场/操作风险加权资产 (RWA)
- **详细 API 参考**：[📄 神州信息核心系统接口参考](./vendors/solutions/dci.md)

### 2.3 高伟达

- **定位**：专注金融信息化，核心系统 + 数字管理平台。
- **代表产品**：核心业务系统、数字管理平台。
- **功能点**：
  - 核心账务、存款、贷款、支付结算
  - 数据中台：监管报表 (EAST/1104)、管理驾驶舱
- **详细 API 参考**：[📄 高伟达核心系统接口参考](./vendors/solutions/gaoweida.md)

## 3. 信贷与风控系统

### 3.1 宇信科技

- **定位**：信贷产品强势，连续斩获头部城商行千万级订单。
- **代表产品**：新一代信贷管理平台、互联网信贷中台。
- **功能点（模块级，下沉到核心功能）**：
  - **进件管理**：授信申请 / 资料录入 / 影像上传 / 人脸核身 / 联合贷分单，~60 功能点
  - **审批决策**：规则引擎 / 评分卡 / 模型服务 / 人工复核 / 工作流，~80 功能点
  - **合同与放款**：合同模板 / 电子签约 / 放款指令 / 受托支付，~50 功能点
  - **贷后管理**：还款计划 / 逾期催收 / 五级分类 / 资产证券化，~100 功能点
  - **风控中台**：反欺诈 / 征信查询 / 授信额度 / 风险预警
- **规模**：完整信贷系统约 500+ 功能点
- **详细 API 参考**：[📄 宇信信贷系统接口参考](./vendors/solutions/yuxin.md)

### 3.2 润和软件

- **定位**：IDC 报告显示数字信贷系统市场份额第一。
- **代表产品**：数字信贷解决方案。
- **功能点**：
  - 智能风控、授信审批、贷后预警
  - 互联网贷款全流程：进件、签约、放款、还款
- **详细 API 参考**：[📄 润和信贷系统接口参考](./vendors/solutions/runhe.md)

### 3.3 神州信息

- **定位**：新一代信贷产品应用于中信银行、农发行、四川农商等。
- **功能点**：见 §2.2，信贷为 Sm@RT 子产品。

## 4. 渠道与支付前置

### 4.1 宇信科技

- **定位**：统一支付平台对接现代化支付系统与清算机构，支撑日均万亿级清结算。
- **代表产品**：统一支付平台。
- **功能点**：
  - 渠道接入：网银、手机银行、第三方支付前置
  - 清算对接：CNAPS 大额/小额、超级网银、银联、网联
  - 业务支撑：聚合支付、分账、对账
- **详细 API 参考**：见 [📄 宇信信贷系统接口参考](./vendors/solutions/yuxin.md) §3 支付前置部分

### 4.2 沐融科技

- **定位**：核心团队具备 RTGS（实时全额支付系统）建设经验，服务央行与商业银行。
- **代表产品**：大型实时清算系统。
- **功能点**：
  - RTGS 核心引擎、排队机制、日终轧账
  - 多边净额清算、流动性管理
  - SWIFT/ISO 20022 报文适配
- **详细 API 参考**：[📄 沐融清算系统接口参考](./vendors/solutions/murong.md)

### 4.3 高伟达

- **定位**：渠道类与支付结算类系统。
- **功能点**：见 §2.3。

## 6. 互联网理财平台（C 端代销）

### 6.1 腾讯理财通

- **定位**：腾讯官方出品的合规第三方基金销售平台，面向 C 端用户。
- **代表产品**：理财通（微信九宫格入口）。
- **功能点**：
  - 基金代销：货币/债券/股票/混合/QDII
  - 智能投顾：组合定投、目标收益
  - 余额+（类货基）、券商资管计划
  - 适当性管理：风险测评、KYC
- **对接方式**：与支付宝/微信支付类似，走开放平台 + 商户签约。
- **详细 API 参考**：[📄 腾讯理财通对接 API 文档](./vendors/wealth/china/tencent-liquetong.md)

## 7. 金融基础软件 / 中间件

### 7.1 东方通

- **定位**：基础中间件厂商，非业务系统供应商，但产品深度嵌入金融基础设施。
- **代表产品**：TongWeb（应用服务器）、TongLINK/Q（消息中间件）、TongSEC（安全中间件）。
- **在 CNAPS 中的作用**：TongLINK/Q 是中国现代化支付系统的关键数据传输组件，保障跨行支付清算数据的稳定传输。
- **功能点**：
  - 消息队列：点对点 / 发布订阅 / 消息追踪
  - 文件传输：断点续传 / 加密传输
  - 集群高可用：多节点、故障切换
- **对接方式**：以 JMS/API 形式集成，非 HTTP 接口。
- **详细 API 参考**：[📄 东方通中间件集成参考](./vendors/solutions/dongfangtong.md)

## 8. 选型建议

### 8.1 按银行类型

| 银行类型 | 核心系统首选 | 信贷系统首选 | 备注 |
| :--- | :--- | :--- | :--- |
| 国有大行 | 神州信息 / 长亮 | 神州信息 | 通常自研 + 多供应商组合 |
| 股份制 | 长亮 / 神州信息 | 宇信 / 润和 | - |
| 城商行 | 长亮 / 高伟达 | 宇信（强项） | 宇信在城商行信贷市场份额高 |
| 农商/农信 | 长亮 / 高伟达 | 神州信息 | - |
| 民营银行 | 润和 / 长亮 | 润和 / 宇信 | 互联网信贷为主 |

### 8.2 按业务场景

| 场景 | 推荐供应商 | 理由 |
| :--- | :--- | :--- |
| 新一代核心系统改造 | 长亮 / 神州信息 | 分布式核心经验丰富 |
| 互联网信贷中台 | 宇信 / 润和 | 互联网贷款全流程产品成熟 |
| 统一支付平台 | 宇信 / 沐融 | 万亿级清结算经验 |
| 央行级清算系统 | 沐融 | RTGS 建设经验稀缺 |
| 财富管理 + TA | 神州信息 / 恒生电子 | 见 [hundsun.md](./vendors/wealth/china/hundsun.md) |
| C 端基金代销 | 腾讯理财通 / 蚂蚁财富 | 流量入口优势 |
| 基础中间件 | 东方通 | 国产化替代首选 |

### 8.3 国产化与信创

金融机构信创替代加速，东方通（中间件）+ 长亮/神州信息（核心系统）+ 国产数据库（OceanBase/TiDB/GaussDB）+ 国产芯片（鲲鹏/海光）已成主流组合。
